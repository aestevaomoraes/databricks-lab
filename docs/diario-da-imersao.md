# Diário da Imersão Engenharia de Dados com IA

## Aula 01 - Introdução ao Databricks

### Data

15/09/2026

### Objetivo da Aula

Conhecer o Databricks Free Edition, compreender o papel da Engenharia de Dados e preparar o ambiente de desenvolvimento.

### Conceitos Aprendidos

- Engenharia de Dados é responsável por coletar, transformar e disponibilizar dados para consumo.
- Databricks é uma plataforma unificada de dados.
- Spark é o motor de processamento utilizado pelo Databricks.
- A arquitetura Medalhão é composta pelas camadas Bronze, Silver e Gold.
- O GitHub pode ser integrado ao Databricks por meio do Git Folder.

### Dataset do Projeto

Fonte: ANAC (Dados Abertos)

Arquivos utilizados:

- Voos e Operações Aéreas
- Aeródromos Públicos
- Empresas Aéreas Nacionais
- Empresas Aéreas Estrangeiras

### Ferramentas Utilizadas

- Databricks Free Edition
- GitHub
- Git Folder
- SQL
- PySpark

### Insights

- O mais importante é entender os conceitos, não apenas a ferramenta.
- A qualidade dos dados influencia diretamente a qualidade das soluções de IA.
- A Engenharia de Dados é a base para Analytics e Inteligência Artificial.
